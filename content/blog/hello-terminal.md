---
title: Why this portfolio is a terminal
date: 2026-10-21
summary: Developers live in terminals. So this site is one.
---

I spend my day in a terminal and in agent CLIs. A site that looks like one felt right.

Commands are fast and honest. Type `/work` and you get the work. No hero section, no scroll-jacking, no carousel. If you do not know what to type, `/help` lists everything.

There is no AI behind it. Every command returns static data that lives in the repo. Nothing is generated and nothing is sent anywhere. What you see is what is in the source.

It is a small Vite and TypeScript app with no framework. The build is a folder of static files, hosted on Cloudflare. That is all.

Try `/help`.
